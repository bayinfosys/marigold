# Workplan 2026-11-20: findings, layers and settings

## Goal

The findings from the 2026-11-19 workplan are fixed, the code follows a
declared set of layers that a script checks on every patch, handlers
receive their settings as an argument, and the task process records how
patches are written and reviewed.

## Context

The code these tasks touch, under package/src/:

- task process: tasks/README.md describes output.patch as `git
  format-patch` output applied with `git am`; patches are now plain `git
  diff` output applied with `git apply`, committed by the maintainer
- host config: cli/host_config.py; HostConfig.compose_env() writes the
  host's own compose variables (MARIGOLD_*), then every [environment]
  key; cli/config.py merges host and application config, the
  application's [environment] winning per key; `application start`
  starts the platform with the merged config; docs/configuration.md is
  generated by scripts/config_doc.py
- loader: models/standard_loader.py raises ModelNotFoundError(modelname)
  from the loader's exception, in four places
- worker: models/worker.py; QueueRunner.run loops on _get_message(),
  and PostgresQueueBackend.receive (backend/messaging/postgres.py)
  returns at once when the queue is empty
- VRAM check: tools/power_sampler.py check_model_vram and
  _extract_named_parameters, which raises NotImplementedError for a
  model that is neither an nn.Module nor a DiffusionPipeline; the http
  handler's model is None and the asr handler's is a transformers
  pipeline
- OpenAI routes: api/routes/openai.py; chat completions returns the
  submission's status code, embeddings returns 400 for any failure
- settings: shared/model_settings.py resolves a ModelSettings for each
  load; set_model_config_env (shared/db_models.py) writes it to
  os.environ, where standard_loader, the txt2img loader and the
  handlers read it (NUM_STEPS, KEYFRAME_MODE, PRECISION and others, 18
  functions)
- request and response schemas: api/models.py, imported by every
  handler under models/, by shared/usage.py and shared/usage_models.py,
  and by the API routes
- catalogue: models/catalogue.py, imported by the API routes,
  shared/receiver_logic.py, the CLI and cache-init
- queue and notification interfaces: backend/messaging/base.py,
  imported by shared/receiver_logic.py, models/worker.py and the
  backends
- worker utilities: tools/power_sampler.py and tools/environment.py,
  imported by models/worker.py and models/entrypoint_handlers.py

The layers, each importing only from those below it, with components
in one layer importing none of each other:

| Layer | Components |
|---|---|
| 3 entry points | cli, tools |
| 2 services | api, models |
| 1 adapters | backend |
| 0 core | shared |

Against these layers the code has 27 violating imports and one cycle
between components. Tasks 0008 to 0011 remove them.

## Findings

- the loader's error message carries only the model name, so
  failed_reason does not say why a model failed to load (0004)
- QueueRunner polls Postgres without sleeping for the length of the
  idle timeout (0005)
- a GPU worker fails to load the http and asr handlers: the VRAM check
  raises NotImplementedError for their models (0006)
- /v1/embeddings answers 400 for a failed model where
  /v1/chat/completions answers 409 (0007)
- [environment] is described as forwarded to every service; a service
  receives a variable only where its compose file names it (0002)
- an application's [environment] can replace any variable
  compose_env() sets, including MARIGOLD_MODEL_SETTINGS, which undoes
  the host's precedence over the application for model settings (0003)
- docs/architecture.md refers to TODO.md, which does not exist (0001)
- handlers read their settings from the process environment, an input
  no argument declares (0013, 0014)
- every handler imports its schema from the API package, models/ holds
  the catalogue, and shared/ imports from api/ and backend/: 27 imports
  against the layers (0008 to 0012)

## Tasks

0000  Record the patch and review process in tasks/README.md: plain
      `git diff` output.patch applied with `git apply`, a one-line
      COMMIT_MSG committed with `git commit -F`, each patch built on
      the committed HEAD, NOTES.md for review questions and answers.

0001  Add TODO.md with the items no workplan addresses: the package
      rename to marigold/{core,cli,api} with a library and CLI split,
      separate application, execution and run identifiers, and the
      last load in `models inspect` being found only within the 50
      most recent events.

0002  Describe [environment] as compose variables that a service
      receives where its compose file names it, in host_config.py, and
      regenerate configuration.md.

0003  Reject an [environment] key that compose_env() already sets, in
      the host and the application config, naming the section that
      sets it.

0004  Include the loader's exception in ModelNotFoundError's message.

0005  Sleep one second between empty polls in QueueRunner.

0006  Check VRAM for handlers without an nn.Module: a handler with no
      model has no weights to place, and a transformers pipeline is
      checked through its model.

0007  Return the submission's status code from /v1/embeddings, as chat
      completions does, so a failed model answers 409.

0008  Move the request and response schemas from api/models.py to
      shared/schemas.py and update every import.

0009  Move models/catalogue.py to shared/catalogue.py and update every
      import.

0010  Move the queue and notification interfaces from
      backend/messaging/base.py to shared/messaging.py and update every
      import.

0011  Move power_sampler.py and environment.py from tools/ to models/
      and update every import.
      Depends on 0006.

0012  Declare the layers in docs/architecture.md and add
      scripts/layer_check.py, which reports cycles between components
      and imports against the layers, and exits 1 when it finds any.
      Depends on 0008 to 0011.

0013  Pass the resolved ModelSettings to each loader as an argument,
      and read the loader settings from it in standard_loader and the
      txt2img loader.

0014  Give each handler its resolved ModelSettings and read handler
      settings from it, and remove set_model_config_env and the
      environment variables it wrote.
      Depends on 0013.

Every patch from 0012 on runs scripts/layer_check.py, which reports no
cycles and no imports against the layers.
