# The CLI in an environment of its own

README.md's quickstart and getting-started.md install the CLI with
`pipx install bayis-marigold` or `uv tool install bayis-marigold`.

Effects:

- the CLI and its dependencies sit in an environment of their own,
  apart from a user's projects and their packages
- the documents give the upgrade and removal commands for both tools
- `pip install bayis-marigold` stays, for installing into a virtual
  environment the user chooses

Depends on 0000.
